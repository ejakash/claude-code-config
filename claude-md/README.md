# claude-md

Global agent instructions installed to `~/.claude/CLAUDE.md`. Covers speech-to-text input quirks, tool-usage preferences (Read/Edit/Grep over Bash equivalents), command hygiene (no compound `cd && cmd`), git commit/PR conventions (no AI-attribution footers), screenshot folder convention, and pointers to language-specific rules plus two optional integrations (wezterm-webview `view`, notification DND).

These instructions are loaded on every session in every project. Keep them generic and short — project-specific rules belong in each project's own `CLAUDE.md`.
