# baseline-settings

Claude Code's `~/.claude/settings.json` baseline: permissions allow-list, plugins, statusLine pointer, model default, plus the `agent-deck` notification hooks.

Does **not** include hooks for cross-cutting tools (those ship in their own repos — see `claude-waiting-notification` and `claude-auto-screenshot`). On a fresh machine, install this module first; cross-cutting modules merge their own hook entries on top.

See `setup.md` for install steps.
